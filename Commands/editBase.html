/editBase

Description

Edits your current base's saved coordinates. Useful if you've moved or made an error when adding it originally.

Permission

Everyone

Syntax

/editBase <x> <y> <z>

Arguments

x is your base's new x coordinate.

y is your base's new y coordinate.

z is your base's new z coordinate.

Examples

Edit Saved Base

Related Commands

addBase removeBase viewBase

Invalid Conditions

You don't yet have a base saved.

Provided coordinates are the same as the saved coordinates.

Provided coordinates are outside build area.

Example - Adding A Base

/editBase -200 75 550

Result

This player's base will be now be saved at the coordinates of -200 75 550.
