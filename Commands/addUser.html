/addUser

Description

Manually adds a user's files. Required for a user to use Minecraft-related commands. /register is preferred if possible.

Permission

Bot Admin

Syntax

/addUser <user>

Arguments

user is the name of the Discord user to add to the database. It is wise to set their server nickname to their Minecraft username first. Required.

Examples

No Examples For This Command.
