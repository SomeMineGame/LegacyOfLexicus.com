/viewBase

Description

Displays the coordinates to the specified player's, or the player running the command if no player is provided, base if they have it saved.

Permission

Everyone

Syntax

/viewBase [player]

Arguments

player is the player you want to receive the base coordinates to. Optional.

Examples

View Current Base View Another Player's Base

Related Commands

addBase editBase removeBase

Invalid Conditions

You don't yet have a base saved and did not request a player.

The requested player doesn't yet have a base saved.

Example - View Current Base

/viewBase

Result

This will display the base coordinates of the player running the command.

Example - View Another Player's Base

/viewBase SomeMineGame
