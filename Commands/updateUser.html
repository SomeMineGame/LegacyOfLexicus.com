CommandBack

/updateUser

Description

Manually updates a player's username. /register is preferred if possible.

Permission

Bot Admin

Syntax

/updateUser <currentname> <newname>

Arguments

currentname is the current username of the player in the whitelist. Required.

newname is the new username for the player. Required.

Examples

Updating A Username

Related Commands

addUser register removeUser requestData

Invalid Conditions

Player not added to the database.

Usernames match.

Example - Updating A Username

/updateUser .SomeMineGame SomeMineGame

Result

This will update SomeMineGame's bedrock username to Java.
