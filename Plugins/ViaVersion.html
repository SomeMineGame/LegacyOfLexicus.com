What Is ViaVersion?

ViaVersion allows newer clients to join older servers. This is helpful for servers that need changed mechanics, a specific version for old modifications, or waiting for current resources to update.

How Do We Use ViaVersion?

We use it to allow newer clients to join while waiting for plugins to upate. Also required when Bedrock updates before the server as they can't change versions.
