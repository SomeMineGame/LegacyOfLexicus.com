What Is Minepacks?

Minepacks is a customizable plugin that adds backpacks for players to use. A player has a singular backpack they can use which ranges from 1-6 rows. It can either be used from the inventory or command depending on the config.

How Do We Use Minepacks?

We use backpacks as a way to store Minecraft's absolute abundance of new items. It is configured for access via inventory and commands and has 54 slots of storage. We also have it kept on death so it's a great place to store spare items.
