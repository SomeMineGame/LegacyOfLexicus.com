What Is AntiPopup?

AntiPopup disables chat signing, so clients think messages are from the server and can't be moderated, filtered, or reported with Mojang's systems. Mods such as No Chat Reports detect this plugin and mark this as a safe server.

How Do We Use AntiPopup?

We use it so that players don't have to fear getting reported over missing context or minor language. We also have a lower age limit that is well within the bounds of some of Mojang's questionable filtering. We do however moderate the server manually, so you will still be responsable for what you say.
