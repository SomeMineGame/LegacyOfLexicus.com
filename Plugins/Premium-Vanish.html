What Is Premium Vanish?

Premium Vanish allows admins to go invisible and hide from all areas of naming, such as player lists and command autofills. The primary use is to catch players that are cheating/hacking.

How Do We Use Premium Vanish?

We use Premium Vanish on the rare occasion a player is reported for cheating/hacking, so they don't know we're watching. Access is only given to admins. Since we can see you when you can't see us, it isn't worth cheating on this server.
