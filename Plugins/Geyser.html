What Is Geyser?

Geyser allows players to join a Java server with their Bedrock client. It emulates the protocols between the two platfroms. By default, it logs you in with your Java account.

How Do We Use Geyser?

We use Geyser to allow players to join on any device that supports server connections. With the help of the Floodgate extension, those who are signed in via Microsoft can use their Bedrock account.
