What Is Simple Voice Chat?

Simple Voice Chat allows users to talk to eachother with mics as long as they are close enough to each other. If you have Sound Physics Overhaul installed, blocks will interfere with your voice chatting as well. This is a Java only feature.


How Do We Use Simple Voice Chat?

We use it so players next to each other don't need to rely on Discord calls or typing. It's also nice to use if you're passing by a friend and want to say a quick "hi".


Where Can You Get Simple Voice Chat?
