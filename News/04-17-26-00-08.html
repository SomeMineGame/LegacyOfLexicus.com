Legacy Of Lexicus Dev Update 2

Hello, SomeMineGame bringing you another development update to the LegacyOfLexicus! First things, you can see I'm working on a new neon theme for the site! It integrates decently with what's already here, so I've published the assets that are common to every page, but every page will be updated very soon. I've had more free time recently so I've been working on the wiki and bot more.

In terms of the bot, I've finally finished the basics of the void system! I still need to add items with variations, such as potions, enchanted books, tipped arrow, those kinds of items. I've also added supply and demand, but will adjust the equation and item values as needed under real world usage. I'm debated on whether to add nations or the player shop next.

I'm also training in one of my friends for web development to hopefully help with the wiki. This would allow me to spend more time on the bot! I won't lie, I did have my doubts on continuing this project, but part of me wants to see it completed, even if it's not utilized much.

As always, the Development page has all the changes as I make them. If you want to help support the project, join the Discord server and use the Nerd server tag! I'm planning on doing live development streams on YouTube, so make sure to look for those! SomeMineGame on YouTube.

We did a trial run on the server and it's almost done. There were some plugins that need tweaking, but other than that, it's just the features I still need to add. I hope you take a look into this project!
